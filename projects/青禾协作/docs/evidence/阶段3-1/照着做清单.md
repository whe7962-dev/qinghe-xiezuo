# 照着做清单 · 阶段 3-1

> 目标：亲手走一遍飞书风格的新界面。测试数据在 `个人资料/测试题A/`。

## 一、启动

1. 打开「终端」，执行：

   ```sh
   cd "/Users/Admin/不能碰/项目开发工程/ai-product-starter-kit-main /projects/青禾协作/backend"
   ./run.sh
   ```

2. 浏览器打开 **http://127.0.0.1:8000**，看到顶部「青禾协作」标题 + 步骤条（载入 → 分析 → 核对 → 导出）即成功。

## 二、走一遍

1. 选「任务表 CSV」=`作业附件-初始工作清单.csv`；「聊天记录 CSV」=`作业附件-A批业务记录.csv`。
2. 点「**载入**」→ 状态显示「任务表 4 行，聊天 10 条」；下方任务表出现 4 行，每行左侧有「已核对」勾选框。
3. 点「**发起分析**」→ 等几秒 → 汇总条显示「本批 N 条建议 · …」；建议按任务分组出现。
4. **看三重编码**：每条卡片有 3 个标签——性质（蓝↻建议修改 / 琥珀⚠待核实 / 灰＝保持原样 / 紫？无法归属）、紧急（高/中/低）、决定（灰○待你决定）。颜色 + 图标 + 文字都有。
5. **看分组**：「保持原样」的建议默认折叠（显示「另有 N 条保持原样（展开）」）；「无法归属现有任务」在底部。
6. **试一次决定**：点某条「采纳」→ 弹出二次确认层，显示「原值 → 新值」+「此操作不可撤销」→ 点「确认采纳」→ 卡片标签变绿「已采纳」+ 下方出现「✓ 已采纳 · 时间」。
7. **试否决**：点「否决」→ 弹层里可填理由（可不填）→ 确认。
8. 勾选任务表某行的「已核对」→ 只是自己的标记，刷新后还在（存本机）。
9. 点「**写回**」→ 点「**导出三份产物**」→ 出现三个下载链接，点「下载 任务表.csv」等能下载。

## 三、手机看一遍

1. 手机上打开同一网址（手机和电脑连同一 Wi-Fi 时，把网址里的 `127.0.0.1` 换成电脑的局域网 IP；或直接让 AI 帮你起）。
2. 窄屏下能正常点「载入 / 分析 / 决定」，任务表可左右滑动看全。

## 四、怎么算通过

- 状态都是「颜色 + 图标 + 文字」三样一起，不靠颜色。
- 「已核对」不进导出；只有「采纳 / 修改后采纳」才写回任务表。
- 采纳/否决/修改后采纳都会弹「此操作不可撤销」二次确认。
- 有异常就截图发给 AI。
