# 照着做清单 · 阶段 2-1

> 目标：亲手走一遍核心闭环。测试数据在 `个人资料/测试题A/`（初始工作清单、A 批、B 批三份 CSV）。

## 一、启动

1. 打开「终端」（Terminal）。
2. 进入后端目录并启动（首次会自动装依赖；没填 Key 会生成 `.env` 后退出）：

   ```sh
   cd "/Users/Admin/不能碰/项目开发工程/ai-product-starter-kit-main /projects/青禾协作/backend"
   ./run.sh
   ```

3. 浏览器打开 **http://127.0.0.1:8000**，看到「青禾协作 · 根据聊天记录更新任务表」页面即算启动成功。

## 二、走一遍（A 批）

1. 点「任务表 CSV」选择 `作业附件-初始工作清单.csv`；点「聊天记录 CSV」选择 `作业附件-A批业务记录.csv`。
2. 点「**载入**」→ 看到状态「已载入：任务表 4 行，聊天 10 条…」，下方「当前任务表」出现 4 行（W-01～W-04）。
3. 点「**发起分析**」→ 看到状态「分析完成：…条建议」。**没有填模型 Key 时会显示「分析失败：缺少模型密钥…」**，这是预期：需要先去 DeepSeek 申请 Key 填到 `backend/.env` 后重试。
4. 逐条看「建议清单」，每条点「待确认 / 采纳 / 否决 / 修改后采纳」。
5. 点「**写回**」→ 只有你点了「采纳 / 修改后采纳」的字段才会改任务表。
6. 点「**导出三份产物**」→ 点「下载」拿到 `任务表.csv`、`建议清单.json`、`变更说明.md` 三份文件。

## 三、B 批 + 重复导入（验证幂等）

1. 用上面导出的 `任务表.csv` + `作业附件-B批业务记录.csv`，重复「载入 → 分析 → 确认 → 写回 → 导出」。
2. 把 `作业附件-A批业务记录.csv` **再载入一次**，看状态里「重复」数量 > 0、新增为 0，且已确认字段没被改掉。

## 四、怎么算通过

- 能载入、能分析、能逐条确认、只有确认的才写回、能导出三份文件。
- 重复导入同一批：不新增行、不产生重复建议、不覆盖已确认字段。
- 测试数据跑出来的结果应与 `docs/PRD/PRD.md` 5.4 验收样例基线一致（A 批 W-01/W-02/W-04 不改、A-08 待核实；B 批 W-01 责任人→周宁、截止日→9 月 19 日）。
